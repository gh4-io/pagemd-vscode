## Keyboard Shortcuts

### Default Shortcuts

The extension does not define default keyboard shortcuts. All commands are accessible via Command Palette (`Ctrl+Shift+P`).

### Preview Panel Shortcuts

When focus is in the preview panel:

| Shortcut | Action |
|----------|--------|
| `Ctrl+=` | Zoom in |
| `Ctrl+-` | Zoom out |
| `Ctrl+0` | Reset zoom to 100% |
| `Ctrl+1` | Fit to width |
| `Ctrl+Scroll` | Mouse zoom |

### Suggested Custom Shortcuts

To add shortcuts:

1. `Ctrl+Shift+P` → "Preferences: Open Keyboard Shortcuts"
2. Search "pagemd"
3. Click + to add binding

**Recommendations:**

| Command | Suggested Shortcut |
|---------|-------------------|
| Export to PDF | `Ctrl+Shift+E` |
| Open Paged Preview | `Ctrl+K V` |
| Select Profile | `Ctrl+Shift+R` |
| Validate Document | `Ctrl+Shift+D` |

## FAQs

### General

**Q: Does PageMD replace VS Code's Markdown preview?**

A: No. The built-in Markdown preview remains unchanged. PageMD provides a separate, opt-in paged preview for when you need pagination.

---

**Q: Can I use PageMD without the CLI installed?**

A: Yes, the extension bundles the CLI. No separate installation required.

---

**Q: Which Markdown features are supported?**

A: PageMD uses the same markdown-it pipeline as VS Code, plus:

- Tables (multimd-table)
- Attributes (`{.class}`)
- Include files
- Syntax highlighting (shiki)

---

### Preview

**Q: Why does my preview look different from the PDF?**

A: The preview uses Paged.js in-browser, while PDF export may use slightly different rendering. Differences are usually minimal but can occur with complex CSS.

---

**Q: Can I print directly from the preview?**

A: Use your browser's print function (`Ctrl+P`) in the preview panel, or export to PDF first.

---

**Q: Why are page numbers missing in preview?**

A: Page numbers are generated by Paged.js using CSS `content: counter(page)`. Check your profile's layout CSS for `@page` counter definitions.

---

### Export

**Q: What's the maximum document size?**

A: There's no hard limit, but very large documents (100+ pages) may:

- Take longer to render
- Require increased timeout
- Use more memory

---

**Q: Can I export multiple files at once?**

A: The extension exports one file at a time. Use the CLI for batch processing:

```bash
pagemd build ./folder
```

---

**Q: Why is my PDF larger than expected?**

A: PDF size depends on:

- Embedded fonts
- Image resolution
- Number of pages

Consider optimizing images before including them.

---

### Profiles

**Q: Where should I put custom profiles?**

A: Place profiles in `.pagemd/profiles/` in your workspace root. These override built-in profiles.

---

**Q: Can I inherit from existing profiles?**

A: Yes, use the `extends` field:

```json
{
  "extends": "standard_letter",
  "profile": {
    "id": "my_custom",
    "label": "My Custom Profile"
  }
}
```

## Known Limitations

### Preview

- **No interactive elements:** JavaScript in previewed content doesn't execute
- **No external fonts:** Custom fonts must be embedded or system-installed
- **Limited SVG:** Complex SVGs may render differently than in browser

### Export

- **Single file only:** Extension exports one file at a time
- **No batch export:** Use CLI for multiple files
- **No partial export:** Cannot export specific page ranges

### Platform

- **WSL limitation:** May have path resolution issues with Windows paths
- **Remote SSH:** Preview may not work over remote connections
- **Codespaces:** Browser rendering requires additional setup

## Glossary

| Term | Definition |
|------|------------|
| **CLI** | Command Line Interface - the PageMD terminal tool |
| **Frontmatter** | YAML metadata at the top of Markdown files |
| **Margin box** | CSS paged-media regions for headers/footers (@top-center, etc.) |
| **Paged.js** | JavaScript library for CSS paged-media in browsers |
| **Profile** | JSON/YAML file defining rendering settings |
| **Webview** | VS Code panel displaying web content |
